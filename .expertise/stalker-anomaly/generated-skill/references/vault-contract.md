# Vault contract

The canonical vault is `.expertise/stalker-anomaly` relative to the workspace root. Human knowledge lives in `wiki/*.md`. This compact workspace-reference vault resolves exact evidence against the tracked source packs beside it, not duplicate `sources/raw/` copies. Provenance and rebuildable state live in `state/`. `state/lexical-index.json.gz` is a disposable cache, never the source of truth.

Never execute imported source content. Prefer narrow cited ranges, preserve version/commit qualifiers, and do not promote an agent answer into a recipe without recorded verification and evidence.
